💊 About ChemistBoys

ChemistBoys is a student-developed online pharmacy and healthcare e-commerce website created as a practical Information Technology project. The main purpose of ChemistBoys is to provide a simple, convenient and user-friendly platform where users can explore healthcare products such as medicines, vitamins, first-aid products, healthcare essentials and other wellness-related items.

The website is designed to demonstrate how an online pharmacy e-commerce system works in a real-world environment. Users can browse products, search for specific items, view product prices, add products to their shopping cart and proceed to checkout.

🎯 Our Purpose

The primary purpose of ChemistBoys is to make the process of finding and purchasing healthcare products simple, organized and convenient through an online platform.

This project also demonstrates the practical implementation of various Information Technology and web development concepts, including user authentication, product management, shopping cart functionality, checkout systems and order management.

🛒 What ChemistBoys Offers

ChemistBoys provides different categories of healthcare products, including:

  • 💊 Medicines and pain-relief products
  • 🍊 Vitamins and supplements
  • 🩹 First-aid products
  • 🌡️ Healthcare equipment
  • 🧴 Personal-care products
  • 🧪 Healthcare essentials

Users can easily browse products, search for required items, check prices and add products to their shopping cart.

🔐 User Features

  • Create an account
  • Login securely
  • Browse healthcare products
  • Search for products
  • Add products to cart
  • Manage cart items
  • Enter delivery details
  • Select a payment method
  • Place orders
  • View orders

📦 Shopping & Order System

ChemistBoys follows a simple e-commerce workflow that allows users to move through the shopping process easily.

Browse Products → Search → Add to Cart → Checkout → Enter Details → Payment → Place Order

🎓 Student Project

ChemistBoys is primarily developed as an educational and practical student project. The project was created to understand how different web technologies can be combined to build a functional e-commerce-style application.

The project provides practical experience in areas such as HTML, CSS, JavaScript, Firebase Authentication, responsive web design and application development.

🚀 Future Vision

The project can be further improved by adding features such as secure online payment verification, advanced order tracking, better product management, inventory management, notifications and a more advanced healthcare shopping experience.
